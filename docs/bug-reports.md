# Баг-репорты

## BUG-1

**Заголовок:** В поле «Номер карты» можно ввести 17 цифр

**Серьёзность:** Major
**Приоритет:** Medium
**Окружение:** Windows 11, Google Chrome 129, http://localhost:9999/?balance=30000&reserved=10000

**Шаги воспроизведения:**
1. Открыть главную страницу F-Bank
2. Нажать на счёт «Рубли»
3. В поле «Номер карты» ввести 55590000000000011

**Ожидаемый результат:** в поле вводится не больше 16 цифр, значение поля «5559 0000 0000 0001».

**Фактический результат:** в поле вводится 17 цифр, значение поля «5559 0000 0000 0001 1». Поле суммы и кнопка «Перевести» при этом доступны, перевод можно отправить на несуществующий номер карты.

**Тест-кейс:** TC-4
**Автотест:** `test_card_number_max_16_digits`

## BUG-2

**Заголовок:** Можно перевести отрицательную сумму

**Серьёзность:** Critical
**Приоритет:** High
**Окружение:** Windows 11, Google Chrome 129, http://localhost:9999/?balance=30000&reserved=10000

**Шаги воспроизведения:**
1. Открыть главную страницу F-Bank
2. Нажать на счёт «Рубли»
3. В поле «Номер карты» ввести 5559000000000001
4. В поле «Сумма перевода» стереть значение и ввести -1000
5. Нажать «Перевести»

**Ожидаемый результат:** отрицательную сумму ввести нельзя (или выводится ошибка), кнопка «Перевести» недоступна.

**Фактический результат:** сумма -1000 принимается, комиссия считается как -100 ₽, кнопка «Перевести» доступна. После нажатия появляется сообщение «Перевод -1000 ₽ на карту 5559000000000001 принят банком!».

**Тест-кейс:** TC-5
**Автотест:** `test_negative_amount_not_allowed`

## BUG-3

**Заголовок:** Нельзя перевести сумму, которая вместе с комиссией ровно равна доступному остатку

**Серьёзность:** Major
**Приоритет:** Medium
**Окружение:** Windows 11, Google Chrome 129, http://localhost:9999/?balance=30000&reserved=10000

**Шаги воспроизведения:**
1. Открыть главную страницу F-Bank (доступно 30 000 − 10 000 = 20 000 ₽)
2. Нажать на счёт «Рубли»
3. В поле «Номер карты» ввести 5559000000000001
4. В поле «Сумма перевода» стереть значение и ввести 18190

**Ожидаемый результат:** комиссия 1 810 ₽, сумма с комиссией 20 000 ₽ равна доступному остатку, кнопка «Перевести» доступна.

**Фактический результат:** выводится «Недостаточно средств на счете», кнопки «Перевести» нет. Перевести весь доступный остаток невозможно (сравнение строгое: остаток должен быть больше суммы с комиссией, а не больше или равен).

**Тест-кейс:** TC-12
**Автотест:** `test_available_balance_boundary[exactly_limit]`

## BUG-4

**Заголовок:** На валютных счетах не проверяется их собственный остаток

**Серьёзность:** Critical
**Приоритет:** High
**Окружение:** Windows 11, Google Chrome 129, http://localhost:9999/?balance=30000&reserved=10000

**Шаги воспроизведения:**
1. Открыть главную страницу F-Bank
2. Нажать на счёт «Евро» (на счету 300 €, резерв 26 €, доступно 274 €)
3. В поле «Номер карты» ввести 5559000000000001
4. В поле «Сумма перевода» стереть значение и ввести 1000

**Ожидаемый результат:** выводится «Недостаточно средств на счете», кнопки «Перевести» нет.

**Фактический результат:** комиссия 100 €, кнопка «Перевести» доступна, перевод 1000 € «принят банком». Остаток проверяется по рублёвому счёту (20 000), а не по выбранному. Так же со счёта «Доллары» (100 $) можно перевести 5000 $.

**Тест-кейс:** TC-13
**Автотест:** `test_foreign_account_uses_own_balance`

## BUG-5

**Заголовок:** Можно перевести 0 ₽

**Серьёзность:** Minor
**Приоритет:** Low
**Окружение:** Windows 11, Google Chrome 129, http://localhost:9999/?balance=30000&reserved=10000

**Шаги воспроизведения:**
1. Открыть главную страницу F-Bank
2. Нажать на счёт «Рубли»
3. В поле «Номер карты» ввести 5559000000000001
4. В поле «Сумма перевода» стереть значение и ввести 0
5. Нажать «Перевести»

**Ожидаемый результат:** кнопка «Перевести» недоступна или выводится ошибка о некорректной сумме.

**Фактический результат:** кнопка доступна, появляется сообщение «Перевод 0 ₽ на карту 5559000000000001 принят банком!».

**Тест-кейс:** TC-14
**Автотест:** `test_zero_amount_not_allowed`
