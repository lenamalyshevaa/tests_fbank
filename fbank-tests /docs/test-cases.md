# Тест-кейсы для F-Bank

**Окружение:** Windows 11, Google Chrome 129, сервис запущен локально.
**Адрес:** http://localhost:9999/?balance=30000&reserved=10000
(на рублёвом счету 30 000 ₽, в резерве 10 000 ₽, доступно 20 000 ₽)

**Карта для перевода:** 5559 0000 0000 0001
