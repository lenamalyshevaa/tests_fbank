# Баг-репорты

## BUG-1

**Заголовок:** В поле «Номер карты» можно ввести 17 цифр

**Серьёзность:** Major
**Приоритет:** Medium
**Окружение:** Windows 11, Google Chrome 129, http://localhost:9999/?balance=30000&reserved=10000

**Шаги воспроизведения:**
1. Открыть главную страницу F-Bank
2. Нажать на счёт «Рубли»
3. В поле «Номер карты» ввести 55590000000000011

**Ожидаемый результат:** в поле вводится не больше 16 цифр, значение поля «5559 0000 0000 0001».

**Фактический результат:** в поле вводится 17 цифр, значение поля «5559 0000 0000 0001 1». Поле суммы и кнопка «Перевести» при этом доступны, перевод можно отправить на несуществующий номер карты.

**Тест-кейс:** TC-4
**Автотест:** `test_card_number_max_16_digits`

## BUG-2

**Заголовок:** Можно перевести отрицательную сумму

**Серьёзность:** Critical
**Приоритет:** High
**Окружение:** Windows 11, Google Chrome 129, http://localhost:9999/?balance=30000&reserved=10000

**Шаги воспроизведения:**
1. Открыть главную страницу F-Bank
2. Нажать на счёт «Рубли»
3. В поле «Номер карты» ввести 5559000000000001
4. В поле «Сумма перевода» стереть значение и ввести -1000
5. Нажать «Перевести»

**Ожидаемый результат:** отрицательную сумму ввести нельзя (или выводится ошибка), кнопка «Перевести» недоступна.

**Фактический результат:** сумма -1000 принимается, комиссия считается как -100 ₽, кнопка «Перевести» доступна. После нажатия появляется сообщение «Перевод -1000 ₽ на карту 5559000000000001 принят банком!».

**Тест-кейс:** TC-5
**Автотест:** `test_negative_amount_not_allowed`

## BUG-3

**Заголовок:** С долларового счёта можно перевести больше денег, чем есть на счету

**Серьёзность:** Critical
**Окружение:** Windows 11, Google Chrome 129, http://localhost:9999/?balance=30000&reserved=10000

**Шаги воспроизведения:**
1. Открыть главную страницу F-Bank
2. Нажать на счёт «Доллары» (на счету 100 $)
3. Ввести номер карты 5559000000000001
4. В поле суммы оставить 1000

**Ожидаемый результат:** сообщение «Недостаточно средств на счете», кнопки «Перевести» нет.

**Фактический результат:** кнопка «Перевести» доступна, перевод 1000 $ принимается банком. Похоже, что остаток проверяется по рублёвому счёту, а не по долларовому. Со счётом «Евро» то же самое.

**Тест-кейс:** TC-6
**Автотест:** `test_usd_transfer_more_than_balance`
